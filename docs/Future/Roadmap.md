# Roadmap

Updated On: 2026-03-30  
Status: Active

이 문서는 아직 구현되지 않은 개선 계획을 다룹니다. 현재 동작의 출처로 사용하지 않습니다.

## 가까운 우선순위

1. `Monitor.ps1`를 현재 실행 구조에 맞게 정렬하거나 공식적으로 정리 대상임을 명확히 하기
2. 문서 업데이트를 더 자동화할 수 있는 체크리스트 또는 CI 검증 추가
3. 패키징 산출물과 저장소 변경 상태를 더 깔끔하게 분리하기

## 중기 개선안

- 대시보드 회귀 테스트 범위 확대
- 데이터 로더 캐시 전략 개선
- 대용량 로그 렌더 성능 계측 자동화
- 패키징 검증 절차 문서화 강화

## 장기 방향

- 에이전트 친화적인 구조 문서 자동 생성
- 로그 스키마 버전 관리
- 배포, 문서, 테스트를 묶는 릴리스 체크리스트 자동화
