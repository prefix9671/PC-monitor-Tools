# 🖥️ PC 리소스 모니터 사용 매뉴얼

이 매뉴얼은 컴퓨터 자원(CPU, 메모리, 저장공간)을 실시간으로 확인하고 기록할 수 있는 **System Resource Monitor** 사용 방법을 안내합니다.

---

## 🚀 1. 프로그램 실행하기

1. Mirtec System Monitor 프로그램을 실행합니다.
    1. 최초 실행 시 관리자 권한으로 실행해야 합니다.
    2. 첫 실행 시 Streamlit이 이메일 주소를 요청하나 엔터 치면 무시하고 실행됩니다.
    
    > *잠시 후 웹 브라우저에 대시보드 화면이 나타납니다.*

![메인 화면](images/main_dashboard.png)

---

## 🎮 2. 제어판 (Control Panel) 사용법

화면 왼쪽의 사이드바를 통해 모니터링 수집을 제어할 수 있습니다.

-   **💡 수집 정책**: 1초 단위로 시스템 자원을 샘플링한 후, 5초 단위로 평균 및 최대값(Peak)을 집계하여 기록합니다. 모든 설정은 모니터링의 완벽한 안정성을 위해 내부적으로 고정되어 있습니다.
-   **Start Monitor**: 이 버튼을 클릭하면 관리자 권한으로 실시간 데이터 수집 프로세스가 시작됩니다. 수집된 데이터는 `C:\SystemLogs` 폴더에 CSV 파일로 저장됩니다.
-   **Refresh Log Data 🔄**: [NEW] 수집 중인 최신 데이터를 즉시 대시보드에 반영하고 싶을 때 사용합니다. 클릭 시 브라우저 캐시를 비우고 로그를 다시 로드합니다.
-   **수집 중단**: 데이터 수집을 멈추려면, 백그라운드에서 실행된 파이썬 콘솔 창을 찾아 닫거나(종료) <kbd>Ctrl</kbd> + <kbd>C</kbd>를 누르면 됩니다.

---

## 📂 3. 데이터 불러오기 (Log File Selection)

저장된 과거의 기록을 분석하고 싶을 때 사용합니다.

1.  **Upload Log CSV(s)**: 본인이 직접 가지고 있는 로그 파일을 업로드할 수 있습니다.
2.  **Select Record Date from C:\SystemLogs**: 날짜 단위로 로그를 선택할 수 있습니다. 
    *   **자동 로드**: **기본적으로 오늘 기준 최근 1주일(7일) 이내의 모든 로그가 자동 선택**되어, 별도 조작 없이도 최대 144시간 이상의 연속 데이터를 바로 확인할 수 있습니다.
    *   **다중 선택**: 여러 날짜를 동시에 선택하여 날짜를 넘나드는 장기적인 리소스 추이를 하나의 그래프에서 분석할 수 있습니다.
3.  **Time Range**: 슬라이더를 조절하여 특정 날짜/시간대의 데이터만 집중적으로 볼 수 있습니다.

---

## 📈 4. 대시보드 활용 및 그래프 조작법

상단의 `Select Dashboard View` 메뉴를 통해 **CPU, Memory, Storage** 각각의 정보를 확인할 수 있습니다.

### 🔍 그래프 확대 및 축소 (Zoom)

모든 그래프 상단에 마우스를 올리면 나타나는 조작 아이콘을 통해 그래프를 자유롭게 제어할 수 있습니다.

![그래프 조작 툴바](images/graph_toolbar.png)

| 아이콘 | 기능 설명 | 주요 사용법 |
| :---: | :--- | :--- |
| 📷 | **Download plot as a png** | 현재 보이는 그래프 화면을 이미지 파일로 저장합니다. |
| 🔍 | **Zoom** | 그래프의 특정 영역을 마우스로 드래그하여 확대합니다. |
| ➕ | **Pan** | 그래프 화면을 마우스로 잡고 사방으로 이동(이동)합니다. |
| ➕ | **Zoom in** | 그래프를 단계별로 확대합니다. |
| ➖ | **Zoom out** | 그래프를 단계별로 축소합니다. |
| ↔ | **Autoscale** | 데이터에 맞춰 축 범위를 자동으로 조절합니다. |
| 🏠 | **Reset axes** | 그래프를 초기 상태(원본 크기)로 되돌립니다. |

*   **특정 영역 확대**: 그래프 영역 안에서 마우스 왼쪽 버튼을 누른 채 **드래그(Drag)**하면 선택한 영역이 확대됩니다.
*   **원래대로 되돌리기**: 그래프 영역을 **더블 클릭(Double Click)**하거나 `Reset axes` 아이콘을 누르면 원래 상태로 돌아옵니다.
*   **축 이동**: 마우스 휠을 굴려 위아래로 이동하거나, 마우스로 그래프를 잡고 끌어 이동할 수 있습니다.



### 📊 엑셀(Excel) 데이터 내보내기

선택한 지표 데이터를 엑셀 파일로 저장하여 정밀한 분석이나 보고서 작성에 활용할 수 있습니다.

![엑셀 내보내기 설정](images/excel_export_ui.png)

1.  상단 메뉴에서 **📈 Custom Graph**를 선택합니다.
2.  분석하고자 하는 지표(CPU, 사용량 등)를 선택하여 그래프를 띄웁니다.
3.  하단의 **📥 Excel Export Settings** 섹션으로 이동합니다.
4.  **Export Start Time**에서 데이터 기록을 시작할 시점을 선택합니다.
5.  **📁 Download as Excel (.xlsx)** 버튼을 클릭하면 엑셀 파일이 생성됩니다.

!!! tip "추가 정보"
    내보낸 파일에는 시간별 수치 데이터뿐만 아니라, 해당 시점의 **상위 5개 메모리/디스크 점유 프로세스 정보**도 함께 포함됩니다.

## 💡 주요 대시보드 설명

### 📊 CPU Dashboard
내 컴퓨터의 두뇌가 얼마나 바쁘게 일하는지, 열은 얼마나 나는지 확인합니다. 사용량이 급증하는 지점을 마우스 드래그로 확대해 보세요.

![CPU 대시보드](images/cpu_dashboard.png)

### 🧠 Memory Dashboard
어떤 프로그램이 메모리를 많이 차지하는지 'Top Offender' 정보를 통해 알 수 있습니다. 전체 메모리 용량 대비 현재 사용량을 한눈에 보여줍니다.

![메모리 대시보드](images/memory_dashboard.png)

### 💾 Storage Dashboard
현재 시스템에 장착된 모든 물리/논리 드라이브의 사용률과 프로그램 IO 사용량을 모니터링합니다.

*   **자동 드라이브 인식**: 수집기 시작 시 **Windows 파티션 정보를 실시간으로 조회**하여, `C:`, `D:`, `E:` 등 모든 인식된 드라이브를 자동으로 감지하고 그래프에 표시합니다.
*   **고도화된 복구 엔진**: [NEW] 과거 로그 오염으로 인해 드라이브가 누락되던 현상을 해결하기 위해 **Regex Self-Healing(정규식 자가 치유)** 로직이 적용되었습니다. 
*   **성능 옵션**: 데이터량이 너무 많아 브라우저가 느려질 경우 상단의 `Chart Quality` 옵션을 조정하여 부드러운 하향 샘플링(Downsampling) 렌더링을 이용할 수 있습니다.

## ⚙️ 5. 자가 진단 및 검증 (For Advanced Users)

개발자나 관리자가 시스템의 무결성을 검증하기 위한 도구가 포함되어 있습니다.

-   **Headless 자가 테스트**: 터미널에서 `.\venv\Scripts\python verify_dashboards.py`를 실행하면 브라우저를 띄우지 않고도 모든 대시보드 렌더링 로직이 정상인지 1초 만에 검증할 수 있습니다.

---

## ❓ 문제 해결 (Q&A)

-   **특정 드라이브(C: 등)가 안 보여요**: 왼쪽 사이드바의 **Refresh Log Data 🔄** 버튼을 눌러보세요. 최신 복구 로직이 적용되어 누락된 드라이브 데이터를 다시 불러옵니다.
-   **로그 파일이 보이지 않아요**: `C:\SystemLogs` 폴더가 생성되었는지, 관리자 권한으로 수집 버튼을 눌렀는지 확인해 보세요.
-   **그래프가 안 나와요**: 왼쪽 사이드바에서 정확한 로그 파일을 선택했는지 확인해 주세요.
-   **데이터가 너무 많아 느려요**: 대시보드 상단의 `Chart Quality`를 `Balanced` 또는 `Fast` 모드로 변경해 보세요.
